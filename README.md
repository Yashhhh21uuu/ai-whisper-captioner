# 🎙 AI Whisper Captioner (Offline & Free)

A real-time and file-based speech-to-text captioning system powered by OpenAI Whisper.

This tool enables:
- 🎤 Live microphone transcription
- 📁 Audio/Video file transcription
- 🔊 System audio captioning (via virtual cable)
- 🧠 Multiple Whisper model sizes
- 💻 Fully offline processing (No API keys required)

---

## 🚀 Features

### 🎤 Real-Time Microphone Captioning
- Captures live audio
- Processes every few seconds
- Displays rolling captions
- Timestamped output
- 50% audio overlap for improved accuracy

---

### 📁 Audio / Video File Transcription
- Supports `.wav`, `.mp3`, `.mp4`
- Generates text transcription
- Automatically saves output file

---

### 🧠 Model Selection

Choose Whisper model based on speed vs accuracy:

| Model  | Speed     | Accuracy |
|--------|----------|----------|
| Tiny   | Fastest  | Basic    |
| Base   | Fast     | Good     |
| Small  | Medium   | Better   |
| Medium | Slow     | High     |
| Large  | Slowest  | Best     |
